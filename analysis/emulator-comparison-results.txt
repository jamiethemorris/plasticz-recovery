PlastiCZ Recovery 0.3.2 — smaller Classic gear and settings matched to each skin
2026-10-10, America/Los_Angeles

New in this build
- Classic gear reduced from 13x13 to 9x9 pixels and moved above the original
  lamp. The icon stays dark; only the button lamp illuminates when open.
- Classic settings use the original brushed-metal texture, new pixel lettering,
  beveled buttons and the original illuminated 4x switch.
- Modern settings match its dark rounded panels, mint accents and typography.
- Settings remain hidden by default; opening preserves panel scale. Interface
  style changes update the settings row immediately without changing sound.
- Automatic bundle dates and ZIP timestamp preservation remain enabled.
- Synth, effects, output processing, preset/state code and original assets are
  unchanged from 0.3.0. All audio comparisons below were rerun for 0.3.2.

The accepted oracle runs original i386 instructions with this Mac's ARM
libSystem math imports; it is not a recording from a historical Intel Mac.
Full-signal exact comparisons above are at44.1kHz, with broader isolated/safety
coverage. They do not establish every note/rate/control combination.
Classic preserves artwork/layout, with native menus and added footer/resizing;
complete original Carbon gestures and meter ballistics are not claimed.

Both bundles are arm64 and locally ad-hoc signed. The original installed plugin
is unchanged. This package is for manual installation, uses a separate identity,
and does not automatically replace original VST2 instances in old DAW sessions.
