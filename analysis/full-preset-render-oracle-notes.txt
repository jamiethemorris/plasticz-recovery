Protocol: plasticz-original-full-factory-c1-v1
- Original i386 voice/control instructions plus original effects/output dispatcher
  0x10e4a execute under Unicorn. No native reconstructed audio function contributes
  to these reference samples. The adapter only interleaves the two returned
  float32 channel byte strings for the unchanged OriginalScheduler.
- All 38 factory float32 parameter words are preserved. In particular, FX type,
  mix, bypass and oversampling are not overridden. All recovered factory presets
  happen to have parameter37=0, so this factory suite does not test 4x mode on.
- "Full" denotes the selected complete signal path. It does not mean forcing
  every effect to 100 percent wet; the original factory mix settings are retained.
- Canonical rate 44,100 Hz; host block512; MIDI note24, channel0, velocity
  float32(100/127); fixed host tempo120 BPM.
- Initialize original DSP/effect objects and parameter setters; render/discard
  512 frames with no held note through the persistent original scheduler.
- Note-on occurs before emitted frame0. Hold88,200 frames (2 seconds); note-off
  occurs exactly before emitted frame88,200, splitting the host block there.
  Render176,400 release frames (4 seconds), total264,600 frames per preset.
- The +0x406a44 float32 control countdown is preserved across preroll, host block
  and note boundaries. At note-on it is17.200027465820312 under this protocol.
- Files are RIFF IEEE float32 stereo (format tag3), little-endian interleaved
  L/R, eight bytes/frame. No clipping, normalization, denoising, alignment or
  removal of bias is applied to emitted reference samples.

Preroll is measured, not asserted silent
- Every short all128 run produced some nonzero no-note preroll. Most peaks are
  about1e-18 to2e-17. Several FX selections produce a larger start-up output;
  the largest observed512-frame preroll peak was0.0037493144627660513, preset97.
- This is recorded evidence of the isolated original initialized signal path,
  not proof that a legacy hosted instance has the identical start-up history.
  No attempt is made to suppress it. Sidecars preserve the preroll payload hash,
  per-channel peak/RMS/mean/nonzero counts, and total frame count.

Runtime/import boundary
- Original x86 instructions are emulated; this is not execution of the VST in
  an old macOS DAW. GUI, licensing wrapper and host integration are not invoked.
- cosf, expf, powf, sinf, cos, pow, sin, fmod, floor and fmax are provided by this
  host's ARM /usr/lib/libSystem.B.dylib, when reached. Memory/allocation imports
  use the helper's bounded per-fixture emulated heap. Historical x86 math-library
  rounding is not established. Actual calls are counted per case.
- Original constructor/parameter helper calls use the helper's recorded control
  words; audio uses DSP x87 control word0x0c3f and SSE MXCSR0x1f80.
- Unknown imports fail closed: the real helper invocation of unresolved import
  0x69000 raised "Unimplemented original import at 0x69000" in the short run.
- Full helper initialization was audited by the parent investigation against
  cached original constructors1454a/14106, sample-rate setter12c9e and parameter
  setter12f4a before authorizing the canonical run. This does not substitute for
  future original-host validation.
- Audited lifecycle scope is44.1kHz. A subsequent read-only audit found that the
  original14106 constructor hardcodes44100 before ed14, which initializes object
  +0x5cc=1/sampleRate; later12c9e does not update that field. The current full
  helper calls superclass ed14 at the requested rate. This does not affect the
  canonical44.1kHz suite, but non-44.1kHz CLI runs are not yet validated against
  the original constructor-then-host-rate lifecycle. Helpers remain frozen while
  this suite runs; other-rate support requires a separate revision/provenance.

Provenance and recovery
- Manifest config pins original binary and factory JSON SHA-256, exporter,
  full DSP helper, dry scheduler module, voice helper, scalar oracle hashes,
  protocol fields, Python/Unicorn/macOS/machine versions and math boundary.
- Dependency hashes are checked before every case and before saving new audio.
  If a helper changes during export, the exporter stops rather than silently
  combining outputs under one provenance identity.
- Resume requires identical configuration/provenance plus verified preset index,
  parameter hash, WAV hash, audio payload hash, sample rate and exact frame count.
  NaN/Inf samples are rejected. WAV then sidecar then manifest are atomically
  replaced individually. A crash between writes leaves a resumable partial case.
- Per-case JSON records all38 float words, per-channel statistics, tail statistics,
  scheduler counts/countdowns, actual import calls and file/content hashes.
- A full_protocol_complete=true summary requires all128 canonical-duration cases.
  A short complete128 smoke suite deliberately reports full_protocol_complete=false.
- This exporter does not compare the current native engine. No native-equivalence
  PASS is implied by successfully exporting an original reference.
